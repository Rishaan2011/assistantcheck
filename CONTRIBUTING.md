# Contributing

Try the quick start, then run `python3 -m unittest discover -s tests -v`.

Useful contributions include a reproducible bug, a synthetic case based on a real assistant failure, clearer setup instructions, or a small implementation with tests. Include expected and actual behavior and your Python version. Do not include API keys, private email, or calendar contents.

Keep the evaluator offline and deterministic. Discuss changes to scoring before implementing them. Avoid adding provider dependencies to the core. For pull requests, explain the problem, behavior change, and validation.
